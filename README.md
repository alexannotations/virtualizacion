# Virtualización y Otros entornos virtuales

Los contenedores son entornos ligeros y portátiles que encapsulan el código fuente junto con sus librerías, dependencias del sistema y variables de entorno, garantizando consistencia idéntica en desarrollo, pruebas y producción.

A diferencia de las máquinas virtuales tradicionales (que virtualizan hardware completo mediante un hipervisor), un contenedor virtualiza a nivel del kernel del sistema operativo, compartiendo los recursos del host de forma segura mediante primitivas de Linux como cgroups (control de recursos) y namespaces (aislamiento de procesos, red y disco).
